## 📝 Project Summary (For Portfolio / Resume)
- **Model Architecture:** YOLOv8 Nano Segmentation (`yolov8n-seg`)
- **Frameworks:** Ultralytics, PyTorch, OpenCV
- **Dataset:** Custom polygon-annotated cattle images
- **Performance Metrics:**
  - **Precision:** 98.7% (Box), 97.8% (Mask)
  - **Recall:** 96.4% (Box), 95.5% (Mask)
  - **mAP50:** 99.0% (Box), 97.2% (Mask)
- **Inference Speed:** ~130ms per image on CPU
